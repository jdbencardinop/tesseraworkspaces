# Feature Request: Add an explicit safe reparent/restack workflow for a single-parent tws stack. Let an operator change one logical entry's configured base to another in-stack parent or explicit Git ref, preview the old parent, recorded cutoff, new destination, replay set, affected descendant closure, branch/ref collateral, metadata changes, and remote/PR retargeting guidance before mutation, then atomically replay the selected branch and required descendants while updating stack.yaml base and last_base_sha only after Git success.
