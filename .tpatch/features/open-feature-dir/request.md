## Description

Allow tws open <feature> (no branch) to open the feature directory itself, not just worktrees. Useful for viewing docs, inject files, decisions. Optionally create a tmux session for the whole feature with --all flag that creates windows for each worktree branch in the same session. This enables a single tmux session to manage the entire feature with tabs/windows per branch.
