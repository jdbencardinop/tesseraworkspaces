# Feature Request: Track which decisions each worktree has already seen. Store a last-read decision ID per branch (in the feature dir or worktree). tws decisions --mine only shows unread decisions. tws decisions ack marks all as read. tws open shows count of new (unread) decisions instead of total. Prevents agents and users from re-reading the same decisions every session.
