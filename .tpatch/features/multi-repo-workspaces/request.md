# Feature Request: Formalize adding worktrees from different repos in the same feature workspace. Currently possible by manually setting paths, but not tracked properly in stack.yaml or tws list/status. Should support: tws new <feature> <branch> --repo /path/to/other/repo, track the source repo per branch in stack.yaml, pass decisions across repo boundaries within the same feature.

**Slug**: `multi-repo-workspaces`

## Description

Formalize adding worktrees from different repos in the same feature workspace. Currently possible by manually setting paths, but not tracked properly in stack.yaml or tws list/status. Should support: tws new <feature> <branch> --repo /path/to/other/repo, track the source repo per branch in stack.yaml, pass decisions across repo boundaries within the same feature.
