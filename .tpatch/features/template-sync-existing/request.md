## Description

Add tws template sync command to backfill template files into existing features. Also add --template flag to tws add for specifying a template directory from anywhere on disk (not just ~/.config/tws/templates or .tws/templates). Support applying multiple templates to the same feature. When files conflict, prompt the user in an apt/dpkg style: keep existing, use new, edit to merge, or show diff.
